# Contributing to LOADUCK

Thank you for your interest in contributing to LOADUCK!

LOADUCK is a free, open-source Windows application written in C++. Contributions, suggestions, bug reports, and improvements are welcome.

## 1. Open Source and Project Ownership

LOADUCK is an open-source project. Its source code is publicly available for viewing, learning, auditing, and contributing, subject to the terms of the project's MIT License.

**Public availability of the source code does not mean that the project has no owner or that its authorship can be claimed by someone else.**

The following principles apply:

- Do not falsely claim to be the original creator or author of LOADUCK.
- Do not present the original LOADUCK project, its development history, or another person's contributions as your own work.
- Do not remove or misrepresent existing copyright notices, author attributions, or license notices.
- If you fork, modify, or redistribute LOADUCK, clearly identify your version as a fork or modified version and provide appropriate attribution to the original project.
- Do not imply that your fork or modified version is the official LOADUCK release or is endorsed by the original maintainer unless explicitly authorized.
- Do not misrepresent the origin of the source code or the contributions made by others.

These guidelines do not prohibit legitimate forks, modifications, learning, or redistribution permitted by the MIT License. All use of the code must comply with that license.

## 3. How to Contribute

You can contribute by:

- Reporting bugs and unexpected behavior.
- Suggesting new features or improvements.
- Fixing issues in the source code.
- Improving documentation.
- Improving performance, stability, and usability.
- Submitting reviewed and tested pull requests.

For major changes, please open an issue first to discuss the proposed approach.

## 4. Pull Request Guidelines

Before submitting a pull request:

1. Check existing issues and pull requests to avoid duplicate work.
2. Explain what your changes do and why they are useful.
3. Keep changes focused on a specific issue or improvement.
4. Test your changes before submitting them.
5. Document relevant changes when necessary.
6. Preserve existing copyright notices and license information.
7. Disclose any third-party code or dependencies introduced by your changes and verify their license compatibility.

Pull requests may be reviewed, requested for changes, or declined at the maintainer's discretion.

Submitting a contribution does not guarantee that it will be accepted or merged.

## 5. Code Quality

When contributing C++ code:

- Follow the existing code style and project structure.
- Prefer clear, maintainable, and readable implementations.
- Avoid introducing unnecessary dependencies.
- Handle errors and resources appropriately.
- Avoid introducing security vulnerabilities or unsafe behavior.
- Do not include secrets, passwords, access tokens, or private information.
- Ensure that changes do not unintentionally break existing functionality.

## 6. Third-Party Components

LOADUCK may use third-party tools and libraries, including yt-dlp and FFmpeg.

Contributors must respect the licenses and terms applicable to third-party components. Any new dependency must be disclosed in the pull request and must be compatible with the project's distribution requirements.

## 7. Respectful Collaboration

All contributors are expected to communicate respectfully and provide constructive feedback.

Spam, harassment, deliberately misleading submissions, and malicious code contributions are not welcome.

## 8. Maintainer Decisions

The project maintainer is responsible for reviewing contributions and deciding which changes are accepted into the official LOADUCK repository.

The maintainer may reject changes that conflict with the project's goals, licensing requirements, security expectations, or technical direction.

## 9. Questions

For bug reports, feature requests, and project-related discussions, use the appropriate sections of the [LOADUCK GitHub repository](https://github.com/slipptech-tech/LOADUCK).

Thank you for helping improve LOADUCK!
