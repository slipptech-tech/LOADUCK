# Privacy Policy

**Project:** LOADUCK  
**Last updated:** October 20, 2026

## 1. Overview

LOADUCK is a free, open-source Windows application for downloading media from supported online services.

- [Official Repository](https://github.com/slipptech-tech/LOADUCK)
- [Latest Releases](https://github.com/slipptech-tech/LOADUCK/releases/latest)
- [Source Code](https://github.com/slipptech-tech/LOADUCK)
- [MIT License](https://github.com/slipptech-tech/LOADUCK/blob/main/LICENSE)

## 2. Information Processing

Depending on the version and features used, LOADUCK may process information such as:

- URLs entered by the user.
- Download history and queue information.
- Filenames and file paths.
- Application settings and media metadata.
- Temporary files and diagnostic information, if implemented.

The actual information processed depends on the application's implementation and configuration.

## 3. Network Connections

When analyzing links or downloading media, LOADUCK and its integrated components may communicate with third-party websites and services.

These services may receive technical information, such as IP addresses and request metadata, according to their own practices.

For more information about third-party components, consult their official resources:

- [yt-dlp — GitHub Repository](https://github.com/yt-dlp/yt-dlp)
- [FFmpeg — Official Website](https://ffmpeg.org/)
- [FFmpeg — GitHub Repository](https://github.com/FFmpeg/FFmpeg)

## 4. Local Data

LOADUCK may store downloaded files, settings, history, or temporary data on the user's computer.

The storage locations and retention behavior depend on the version and configuration. Deleting local data does not necessarily remove information already retained by third-party services.

## 5. Data Collection and Sharing

This policy does not guarantee that every version of LOADUCK operates without network communication or data transmission.

Users can review the [public source code](https://github.com/slipptech-tech/LOADUCK) to investigate the application's behavior.

Any telemetry or additional data collection, if introduced, should be documented accurately.

## 6. Security

Download LOADUCK only from the [official releases page](https://github.com/slipptech-tech/LOADUCK/releases).

For information about reporting potential vulnerabilities, read the [Security Policy](https://github.com/slipptech-tech/LOADUCK/blob/main/SECURITY.md).

## 7. Policy Updates

This policy may be updated as LOADUCK's functionality, dependencies, or data-handling practices change.

Check the [latest version of this document](https://github.com/slipptech-tech/LOADUCK/blob/main/PRIVACY.md) for updates.

For questions, feedback, or privacy-related concerns, visit the [LOADUCK GitHub repository](https://github.com/slipptech-tech/LOADUCK) or open an [issue](https://github.com/slipptech-tech/LOADUCK/issues).
