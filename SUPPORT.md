# Support

Need help with LOADUCK? This document explains how to get support, report problems, and request improvements.

## Official Repository

The official LOADUCK repository is:

https://github.com/slipptech-tech/LOADUCK

Please use the official repository for project-related questions, bug reports, and feature requests.

## Bug Reports

If you encounter a bug or unexpected behavior, please open a GitHub Issue:

https://github.com/slipptech-tech/LOADUCK/issues

When reporting a problem, include as much of the following information as possible:

- LOADUCK version.
- Windows version and architecture.
- Steps to reproduce the problem.
- Expected behavior and actual behavior.
- Relevant error messages or logs.
- Screenshots, if they help explain the issue.

Please remove passwords, access tokens, personal information, and other sensitive data before sharing logs.

Before opening a new issue, check whether the problem has already been reported.

## Feature Requests

Have an idea for improving LOADUCK?

Open an issue in the official repository and describe:

- The feature you would like to see.
- The problem it would solve.
- How you think it should work.

Feature requests are reviewed at the maintainer's discretion. Submission does not guarantee implementation.

## Security Issues

**Do not report security vulnerabilities in public issues.**

Please follow the instructions in [SECURITY.md](SECURITY.md) to report potential security vulnerabilities responsibly.

## Contributing

Contributions are welcome! Before submitting code changes, please read [CONTRIBUTING.md](CONTRIBUTING.md).

## Third-Party Components

LOADUCK may depend on third-party tools and services, including yt-dlp and FFmpeg.

If a problem originates in a third-party component, consult the relevant project's official documentation and support resources. Issues involving LOADUCK's integration with these components should be reported to the LOADUCK repository.

## Support Limitations

LOADUCK is provided free of charge and on an "AS IS" basis, subject to the applicable project license.

Support is provided on a best-effort basis. There is no guaranteed response time, support schedule, or promise that every issue or feature request will be addressed.

Thank you for using LOADUCK!
