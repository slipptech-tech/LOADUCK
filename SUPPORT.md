## Bug Reports

Before reporting a bug, please check [existing issues](https://github.com/slipptech-tech/LOADUCK/issues).

When opening a report, include:

- LOADUCK version.
- Windows version.
- Steps to reproduce the problem.
- Expected and actual behavior.
- Relevant error messages or screenshots.

Please remove passwords, access tokens, and other sensitive information before submitting logs.

## Feature Requests

Have an idea for LOADUCK? [Open an issue](https://github.com/slipptech-tech/LOADUCK/issues/new) and describe the proposed feature and the problem it would solve.

## Security Issues

Please do not publicly disclose unpatched security vulnerabilities. Follow the instructions in the [Security Policy](https://github.com/slipptech-tech/LOADUCK/blob/main/SECURITY.md).

## Contributing

LOADUCK is free and open source. Support is provided on a best-effort basis, without guaranteed response times.
